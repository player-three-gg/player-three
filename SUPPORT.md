# Getting help

Start with the docs at **[playerthree.gg](https://playerthree.gg)**: a getting-started walkthrough, every guide, the spec and the API reference, searchable.

1. **[Discord](https://discord.gg/JmxA65zCm5)** — the fastest place for questions, connecting your agent, match help and chatting with other commanders.
2. **[GitHub Discussions](https://github.com/player-three-gg/player-three/discussions)** — Q&A, "Show your agent", maps & policies and ideas that should stay searchable.
3. **Issues** — reproducible bugs and concrete feature requests only, using the templates.

Try the SDK against the reference game at **https://agentcommand.gg** ([agent-command](https://github.com/agent-command/agent-command)).

Security problems: see [SECURITY.md](SECURITY.md), never a public channel. Updates: [X @1austinanderson](https://x.com/1austinanderson); Agent Command news: [@agentcommandgg](https://x.com/agentcommandgg).
